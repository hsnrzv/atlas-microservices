# ADR-0007: Java 21, Spring Boot 4.1 and the Maven Wrapper as the backend baseline

- Status: Accepted; the Java 21 part is superseded by [ADR-0008](0008-java-25-lts-runtime.md) (Java 25 LTS)
- Date: 2026-11-12
- Deciders: @hsnrzv (owner)

## Context

`project-instruction.md` §9.3 proposes Java 21 LTS, Spring Boot 4.1.x and a Maven Wrapper build. The
cross-repository contract verified these versions on 2026-11-12. Phase 1 needs a reproducible build that
works the same on a developer machine and in GitHub Actions. The owner's machine has JDK 25 as the
default `java`, and JDK 21 is installed separately.

Verified on 2026-11-12:

- Spring Boot 4.1.2 requires Java 17+ and supports up to Java 27, Maven 3.6.3+ and Tomcat 11.0.x.
  (Spring Boot system requirements.)
- Spring Boot 4.1.2 manages Spring Framework 7.0.10, Spring Security 7.1.2, Hibernate ORM 7.4.13.Final,
  Flyway 12.4.0, Testcontainers 2.0.5, JUnit Jupiter 6.0.3 and Jackson 3.1.7. Spring Modulith 2.1.1 is
  the matching release generated by start.spring.io.
- endoflife.date lists open-source support for Spring Boot 4.1 until 2027-07-31 and Eclipse Temurin 21
  until 2029-12-31 (to re-check on spring.io and adoptium.net before release planning).

## Decision

- **Java 21 LTS** (`<java.version>21</java.version>`). The Maven Enforcer rule `requireJavaVersion [21,)`
  fails the build on older JDKs. Container images use `eclipse-temurin:21-jdk-noble` (build) and
  `eclipse-temurin:21-jre-noble` (runtime). CI uses Temurin 21 through `actions/setup-java@v6`.
- **Spring Boot 4.1.2** through `spring-boot-starter-parent`, with Boot 4's modular starters
  (`spring-boot-starter-webmvc`, `spring-boot-starter-flyway`, `spring-boot-starter-webmvc-test`, ...).
  **Spring Modulith 2.1.1** comes through its BOM.
- **Maven Wrapper 3.3.4** (`only-script` distribution, **Maven 3.10.0**). `./mvnw` is the only supported
  entry point; Enforcer `requireMavenVersion [3.10.0,)` keeps local and CI builds aligned with the
  wrapper. `dependencyConvergence` and `banDuplicatePomDependencyVersions` are enforced.
- Tests: JUnit Jupiter from the Boot BOM. Unit and modularity tests run with Surefire (`*Tests`), and
  Testcontainers integration tests run with Failsafe (`*IT`) in `./mvnw verify`.
- Upgrades: Dependabot proposes Spring Boot/Modulith minor and patch updates weekly (grouped). A new
  Spring Boot minor/major or Java LTS is adopted by a PR that updates this ADR (or supersedes it) and
  the cross-repository contract.

## Consequences

- Developers must set `JAVA_HOME` to a JDK 21+ (documented in the README). Building with JDK 25 also
  works, but the reference toolchain is 21.
- Boot 4 brings Jackson 3 (`tools.jackson` packages), JUnit 6, Testcontainers 2 artifact names and the
  split starters. Older Boot 3 examples are often not applicable.
- Moving to Java 25 LTS later is expected to be a small change. It is a deliberate decision, not a
  Dependabot update, because the Docker ecosystem ignores Temurin major updates.
- The Spring Boot 4.1 support window means a planned upgrade to the next minor within roughly a year.

## Alternatives considered

- **Java 25 LTS now:** newer language/runtime features, but the spec and contract fix Java 21, and
  some tooling support may lag behind. Revisit after the MVP.
- **Spring Boot 3.5.x:** longer commercial support history, but it is the previous generation. Starting a
  new project on it would force a Boot 4 migration soon.
- **Gradle:** faster incremental builds and a flexible DSL. The spec and team familiarity favour Maven,
  and the wrapper gives the same reproducibility.
